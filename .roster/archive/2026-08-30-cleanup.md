# Cleanup of loose ends from the auth/profile foundation task

## Spec

Four polish items, none blocking:

1. **`authConfigured` name collision.** `e2e/auth-session.spec.ts:9` defines
   `authConfigured = Boolean(process.env.AUTH_SECRET?.trim())` (session-readiness,
   matches `isAuthSessionConfigured()`); `e2e/login.spec.ts:9` defines
   `authConfigured = googleAuthEnvironmentKeys.every(...)` (full Google provider
   readiness, matches `isGoogleAuthConfigured()`). Same name, different meaning.
   Rename: `auth-session.spec.ts` -> `sessionConfigured` (already has
   `googleConfigured`); `login.spec.ts` -> `googleConfigured`. Update all
   references and skip messages. Skip logic and assertions unchanged.

2. **redirect-pin explanation duplicated in three places.** Full explanation in
   `src/auth.ts:12-24` (code comment), `docs/auth-architecture.md:23`
   (Routes and redirects), and `docs/auth-architecture.md:107` (Threat model).
   Keep Routes and redirects authoritative; reduce Threat model to a brief
   statement + cross-reference; trim `src/auth.ts` comment to 3-5 lines + pointer
   to the doc. `redirect({ baseUrl })` implementation untouched -- prose/comments
   only.

3. **`NavigationLink` exported without consumers.**
   `src/components/mobile-navigation.tsx:17` exports the type; only used at line
   25 of the same file; `header.tsx` does not import it. Remove the `export`
   keyword (make module-local). Do not move, rename, or add a consumer.

4. **raw Google sign-in test hits real network.**
   `e2e/auth-session.spec.ts:112-138` POSTs `/api/auth/signin/google`, triggering
   OIDC discovery to `accounts.google.com`. Confirmed via `@auth/core` source:
   `init` sets `authjs.callback-url` but `Auth` returns it only if
   `getAuthorizationUrl` succeeds; on discovery failure it redirects to the
   error page without the cookie. So the test fundamentally requires network.
   Guard with a reachability probe (one `fetch` to
   `.../.well-known/openid-configuration`, 3-5s timeout, cached boolean); skip with
   a clear message when unreachable. No mocks, no test-only provider switches
   (prohibited by Threat model), no test removal.

Out of scope: historical `docs/superpowers/plans/` are decision records -- not
edited. No git commits or branch changes.

Verification: `npm run lint`, `npm run build`, `npm test` (Playwright). The
Google signin cookie test must still run+pass when network is available and skip
(not fail) when unavailable.
